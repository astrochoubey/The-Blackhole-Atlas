# Black Hole Atlas

Black Hole Atlas is an interactive web-based astronomy platform for exploring known black holes and understanding their physical properties, observational history, and location in the universe.

The platform combines a curated database of observed black holes with physics-based calculations and interactive visualizations. Users can explore objects such as Sagittarius A*, M87*, Cygnus X-1, and other known black holes, compare their physical characteristics, and investigate how astronomers determine their properties.

The application provides information such as black-hole mass, distance, host galaxy, classification, coordinates, discovery/observation methods, and measurement uncertainties. From these observational parameters, the system calculates scientifically motivated quantities such as Schwarzschild radius, Eddington luminosity, Hawking temperature, characteristic timescales, orbital properties, and other relevant relativistic quantities where applicable.

A major component of the project is an interactive visualization layer. Users can explore the spatial relationship between Earth and known black holes, visualize their astronomical coordinates, compare different black holes, and interact with graphs showing relationships between physical properties.

The project is designed to bridge astronomical data, theoretical physics, backend engineering, databases, and scientific visualization in a single application.

## Core Objectives

- Build a structured database of known black holes and their observational properties.
- Provide APIs for searching, retrieving, comparing, and analyzing black-hole data.
- Implement a physics engine for deriving additional physical quantities from observational parameters.
- Create interactive visualizations for black-hole properties and distributions.
- Represent observational uncertainty and distinguish measured properties from calculated quantities.
- Provide sources and references for astronomical data used by the application.
- Develop a responsive frontend that makes complex astrophysical information accessible and interactive.

## Proposed Features

- Known black-hole catalog
- Search and filtering
- Individual black-hole profiles
- Black-hole comparison tool
- Physics calculator
- Interactive graphs
- Astronomical coordinate visualization
- Earth-to-black-hole distance visualization
- Observation/discovery information
- Measurement uncertainties
- Data sources and scientific references
- Optional 3D astronomical visualization

## Vision

Black Hole Atlas aims to demonstrate how software engineering can be used as a tool for exploring and communicating modern astrophysical knowledge.
